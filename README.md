# Cat Vs Dog Image Classification

A deep learning project developed in Python as part of a data science portfolio.

## Overview

This repository demonstrates an end-to-end data science workflow, including exploration, preprocessing, modeling, and evaluation where applicable.

## Technologies

`cv2`, `matplotlib`, `numpy`, `pandas`, `sklearn`, `tensorflow`

## Main files

- `cat-vs-dog-image-classification-using-cnn.ipynb`
- `app.py`
- `app1.py`
- `app2.py`
- `app3.py`
- `app_cnn.py`

## Getting started

1. Clone this repository.
2. Create a Python virtual environment.
3. Install the libraries imported by the notebook or application.
4. Open the notebook in Jupyter and run the cells in order.

Large, private, generated, or duplicate artifacts are intentionally excluded from this repository. They will be linked from Kaggle or Hugging Face where appropriate.
